# AVR Kumar · Personal website

Live at **https://avrkumar-25.github.io**

## Files

| File | Purpose |
|---|---|
| `index.html` | The complete website: text, design, photos and fonts are all inside this one file |
| `avr-kumar-linkedin.jpg` | Preview image shown when the link is shared on LinkedIn, WhatsApp and similar apps |
| `404.html` | Page shown for broken links |
| `.nojekyll` | Tells GitHub to publish the files as they are |

## Updating the site

Upload a new `index.html` with **Add file → Upload files**, then **Commit changes**. The site updates within a couple of minutes.

## Visit log

Visits and opened stories are recorded in a private Google Sheet. The logger address is set in the **SITE SETTINGS** section near the top of `index.html` (`visitLogUrl`). To stop your own visits being recorded, open the site once with `?nolog` at the end of the address in each browser you use.
